# 🍔 Дипломный проект. Задание 3: UI тесты Stellar Burgers

## 📋 Задание 3: Автоматизация UI тестов с поддержкой двух браузеров

### 🎯 Цели задания:
- Протестировать функциональность в Google Chrome и Яндекс.Браузере
- Использовать Page Object для описания элементов
- Подключить Allure-отчёт
- Покрыть тестами: регистрацию, вход, раздел "Конструктор"

## 🚀 Быстрый старт

### Требования:
- Java 11 или выше
- Maven 3.8 или выше
- Google Chrome (последняя версия)
- Яндекс.Браузер (опционально)

### Запуск тестов в Chrome (по умолчанию):
```bash
# Запуск всех тестов
mvn clean test

# Запуск конкретного тестового класса
mvn test -Dtest=RegistrationTest
mvn test -Dtest=LoginTest
mvn test -Dtest=ConstructorTest

# Генерация Allure отчета
mvn allure:report

# Открыть отчет (macOS)
open target/site/allure-maven/index.html
Запуск тестов в Яндекс.Браузере:
bash
# Установите Яндекс.Браузер и укажите путь к нему в BaseTest.java
mvn test -Dbrowser=yandex
